##### **2. タイムスタンプ形式の統一**

```
【形式】
YYYY-MM-DDTHH:MM+09:00

【例】
2026-10-22T16:00+09:00

【タイムゾーン】
必ず +09:00（日本標準時）を付与

【注意】
- スペースは入れない
- +09:00 は必須（タイムゾーンの明示）
- 秒単位の精度は不要（分単位で統一）
```

##### **3. 更新時の必須項目**

エージェントがデータを更新する場合、**必ず以下を実行：**

```
【ステップ1】該当エージェントの「最終実行」を現在時刻に更新
例：
  "最終実行": "2026-10-22T16:00+09:00"

【ステップ2】ルート直下の「最終更新」を現在時刻に更新
例：
  "最終更新": "2026-10-22T16:00+09:00"

【ステップ3】変更内容を「備考」に記録（オプション）
例：
  "備考": "【T005実行】フルリモートワーク計画案を追加 by 分析エージェント"

【ステップ4】コミットメッセージに変更内容を記載
例：
  "T005作成。分析エージェント実行。フルリモートワーク計画案追加"
```
